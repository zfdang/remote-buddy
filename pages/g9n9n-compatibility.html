G9N9N 语音与按键使用指南

市面上的 G9N9N 遥控器即使 VID/PID 同为 18D1:9450、DIS 型号同报 A0，在 macOS 上的 HID 按键报告格式也存在三种不同的硬件或固件表现。Remote Buddy 会读取并在「遥控器连接」页展示 HID 版本（来自蓝牙 PnP ID 0x2A50 与公开 IOHID kIOHIDVersionNumberKey），便于快速核对所属批次与支持模式。

已知 HID / 固件批次 当前支持状态 普通按键报告格式与长度 macOS 系统层识别表现 Remote Buddy 支持模式与功能边界
HID 版本 0x0110
已实测完全支持		 完全支持 Report ID 1，描述符 3 字节，固件实际发送完整 3 字节索引格式（例如松开 01 00 00）。 单键按下与松开均正常通过 BTLEServer 上送公开 IOHID。 Fully Supported（完全支持模式）：语音键（含智能切换与约 5 分钟保活）+ 全部 14 颗普通按键的单击、双击、长按与单键常用语。
DIS A0 / 固件 26.7
已实测部分支持		 部分支持 Report ID 1，描述符声明 2 槽位（含 ID 共 3 字节），但单键按下与松开固件仅发送 1 字节（03 / 00）。 单键与松开短报告被 macOS 丢弃；仅同时按两个键填满 2 字节（如 01 03 0B）才能进入 IOHID。 Partially Supported（部分支持 / 双键兼容模式）：语音键可正常使用；普通按键仅「方向键 + OK」（如「上 + OK」）可发送 Enter 键；14 颗普通单键、双击／长按及单键常用语不可用。
HID 版本 0x011B
社区实测反馈		 仅语音可用 Report ID 2（小端 16-bit consumer usage），描述符声明不含 ID 为 3 字节，固件实际仅发送 2 字节（如按下 42 00、松开 00 00）。 因实际长度与描述符不符，所有普通按键报告均在 macOS BTLEServer 层被丢弃，公开 IOHID 连双键组合也收不到任何普通按键。 仅语音键可用（普通按键不受公开接口支持）：ATVV 语音键走独立通道仍可正常录音；应用严格遵循仅调用公开系统 API 原则，建议退换为 0x0110 批次硬件或更换其他支持型号。
关键说明与版本鉴别： 连上 Mac 后，可在 Remote Buddy 设置 → 遥控器连接 → 硬件信息查看 HID 版本（如 0x0110 或 0x011B）和固件版本号。如果单键无法触发、只能靠双键组合识别，必须由用户在向导中主动勾选确认才会进入部分支持模式，程序不会绕过确认自动降级。若属于 0x011B 等连双键都无法到达 IOHID 的批次，普通按键无法通过公开系统接口接收，建议更换为已验证完全支持 macOS 的 0x0110 硬件或其他支持遥控器；兼容款硬件批次与购买链接可参考 支持设备与选购指南 →（项目维护者实购验证的 0x0110 批次：拼多多参考链接（实购约 ¥15）↗）。

首次设置与按键映射模式

型号名称或相同的 VID/PID（18D1:9450）不能代替实际按键测试；向导会根据您的真实按键结果锁定对应支持模式。

1. 首次设置与模式识别

蓝牙配对与向导第 2 步判定
向导引导
  • 蓝牙配对：在 macOS「系统设置 → 蓝牙」连接遥控器；进入配对状态时同时按住「返回 + 主页」约 3 秒。
  • 先单按 OK 键：在向导选择 G9N9N 后先单独按一次确定（OK）键。若成功收到单键输入，则直接判定为完全支持模式，随后依次测试三个不同的普通按键即可进入语音配置。
  • 单按无反应时尝试「上 + OK」：向导会提示同时按住任意方向键与 OK（例如「上 + OK」）。若仅双键组合触发输入，需由您主动勾选「确认进入部分支持（兼容）模式」，并验证一次「方向键 + OK」可用后继续。

2. 按键映射与兼容模式边界

完全支持 vs. 部分支持（双键兼容）
按模式隔离
  • 完全支持模式（14 颗普通按键）：方向、OK、返回、主页、静音、音量加减、YouTube、Netflix、输入源和电源共 14 颗按键均可配置单击、双击与长按。默认媒体动作：YouTube 上一首、Netflix 下一首、输入源播放／暂停；整机重置与单项「恢复默认」使用同一套型号默认动作。
  • 部分支持模式（只读锁定）：在向导中确认启用后，设置页仅作只读展示（不在设置页自由切换或修改单个键位），固定响应「方向键 + OK」→ 发送一次 Enter（回车），并隐藏不适用的 14 颗单键及单键常用语编辑项。
  • 更换完全支持款硬件后：请在「遥控器连接」页移除旧设备，再点击「添加新设备」通过向导重新完成单键检测。

语音操作与硬件报告边界

两种支持模式下的语音录制与输出体验完全一致；普通按键仅在公开 HID 报告安全且确定时开放自定义。

语音键与智能切换

ATVV 独立音频通道 · 不受普通按键模式影响
全批次通用
  • 固定麦克风角色：Google Assistant 语音键始终绑定为遥控器麦克风输入，音频送入虚拟麦克风 Remote Buddy Mic，再交给微信输入法、豆包、Voice Buddy 等工具识别；底部白色指示灯在传输期间常亮，电量服务可读时显示百分比。
  • 智能切换（默认）：短按并松手后保持免提持续收音（再按一次或按其他键停止）；若按住超过 0.7 秒，则松手立即停止。也可在设置页切换为纯「按住说话」。
  • 突破 60 秒时长上限：两种触发方式均支持后台定期保活，最长约 5 分钟自动停止以防忘记关麦耗电。

硬件边界与诊断排查

公开 IOHID 接口与安全约束
设计边界
  • 不做无松开报告的双键猜测：部分支持模式下不会通过双键组合反向推断全部 14 颗单键，也不开放缺乏松开报告时的长按连发，仅稳定提供「方向键 + OK」模拟 Enter；已识别的短零值松开报告会清除按键状态，不会误触发电源键。
  • 不读取系统私有调试日志：针对 0x011B 等被 macOS BTLEServer 丢弃的报文批次，应用不会绕过系统隐私与公开 API 边界提取底层报文。
