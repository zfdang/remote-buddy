开始使用

安装后，跟着向导开始。

应用和虚拟麦克风驱动包含在同一个安装包中，可从官网镜像或 GitHub Releases 下载。

查看常见问题排障 ↓
  1. 01

    安装并打开

    选择适合 Mac 芯片的安装包（PKG）完成安装，再从“应用程序”打开 Remote Buddy。

  2. 02

    授权与驱动就绪

    按向导授权蓝牙、输入监控和辅助功能，并确认 Remote Buddy Mic 虚拟麦克风驱动就绪。

  3. 03

    连接、选热键与配工具

    连接遥控器并测试按键，选择发送给输入工具的语音热键（Fn 或自定义快捷键）与点按方式，再在输入工具中完成配置。

  4. 04

    试说一句话

    通过向导中的语音测试使配置生效，点击要输入文字的位置，按住遥控器语音键说话、松开结束；点按模式则自动按热键开始与结束。

常见问题

遇到按键或 Fn 语音没反应？先排查这几项。

语音正常，按键却没反应？先检查 Karabiner-Elements 等按键工具的设备占用。

这类工具可能独占遥控器，导致遥控搭子收不到按键。典型表现是普通按键无法执行已配置的动作，而蓝牙连接或语音仍然正常。小米遥控器的默认映射中，主页键切换应用、TV 键播放/暂停、电源键退格、返回键发送 Escape。

  1. 在 Karabiner-Elements 中打开 Devices（设备），找到你的遥控器，例如“小米蓝牙语音遥控器”。
  2. 关闭这只遥控器的 Modify events，把它交给遥控搭子处理。其他键盘的设置可以保留。
  3. 重新连接遥控器，或重启遥控搭子，再到“按键映射”检查连接状态，测试主页键、TV 键、电源键与返回键。

若仍提示“设备被其他输入工具占用”，可重启 Karabiner-Elements 后再试；同时检查遥控搭子的输入监控与辅助功能权限。

Karabiner 官方设备设置说明 ↗
选择 Fn 键触发语音，却没反应或被微信截获？检查微信全局快捷键占用。

macOS 版微信（WeChat App）可能在后台注册了全局 Fn 快捷键（例如全局语音输入或其他功能热键）。一旦被微信占用，按下遥控器发送的 Fn 会先被微信拦截，导致你选择的第三方语音输入工具（如豆包、微信输入法、Typeless 等）无法收到触发信号。

  1. 打开桌面端微信 → 设置 → 快捷键（部分版本在聊天/通用设置内）。
  2. 检查是否存在占用 Fn（或 🌐 地球键）的全局快捷键，尤其是语音输入相关热键。
  3. 如有冲突，请更换或仅清除冲突的 Fn 快捷键（无需修改微信其他快捷键）。
  4. 返回目标输入工具或遥控搭子的向导测试页，重新按下遥控器语音键试说一句。

如果无法取消微信对 Fn 的占用，也可以在“输入法集成 → 语音热键”中改用 Ctrl (⌃) + Option (⌥) + V 等其他组合快捷键。

选择 Fn 键作为语音热键，系统设置里务必设为“不执行任何操作（Do Nothing）”。

若你在遥控搭子中选择 Fn/地球键 给第三方语音工具使用，但按下语音键时屏幕却弹出表情符号面板、切换系统输入法或触发系统听写，通常是因为 macOS 系统先行拦截并消费了 Fn 按键。

  1. 打开 macOS 系统设置（System Settings）→ 键盘（Keyboard）。
  2. 找到 按下 🌐 键时（Press 🌐 key to） 下拉菜单，将其设为 不执行任何操作（Do Nothing）。
  3. 如在其它软件中不希望按 Fn 弹出表情或切换输入法，改完后系统即会直接放行 Fn 给语音输入工具使用。

注意：如果你选择的工具本身就是 macOS 听写，则不要禁用系统 🌐 键——请保留系统听写设置，并按向导说明在“听写 → 快捷键”中选择“按两下 🌐 键”。

隐私、安全与安装

遥控搭子完全开源、纯本地运行，绝不留存你的任何声音或文字。

关于遥控搭子（Remote Buddy）本身

  • 不保存录音与文字：所有蓝牙语音仅在本地内存实时解码并送入虚拟麦克风，软件本身不做语音识别，也不记录录音文件或转录文本历史。
  • 零遥测、零自动上传：不采集使用统计、不植入第三方分析 SDK，也不会在后台上传任何诊断日志或设备数据（日志仅存本地，需你主动复制/查看）。
  • 代码与驱动完全开源：主程序与内嵌的 Remote Buddy Mic 虚拟麦克风驱动源码均以 GPL-3.0-only 开源公开，可随时审计或自行编译。
  • 权限边界清晰：仅通过 macOS 公开系统接口与辅助功能工作，不读取其他应用的私有数据。

关于你选择的输入法与语音工具（独立边界）

语音经 Remote Buddy Mic 交给输入工具后，识别与文本上屏由该工具独立完成。不同工具是否完全离线运行或需要联网处理，取决于你所选工具自身的隐私政策与设置——遥控搭子不参与、也无法读取其识别过程。若希望整条链路始终保持在本地设备内，可搭配 100% 本地离线运行的 Voice Buddy（语音搭子）。

安装与签名说明：安装包内含 Remote Buddy Mic 虚拟驱动，首次安装或驱动更新需管理员授权并会短暂重启音频服务。当前 PKG 安装包尚未经过 Apple Developer ID 公证，首次安装若被系统拦阻，可在“系统设置 → 隐私与安全性”中允许安装（源码及签名细节见 构建与签名说明 ↗）。
