# G9N9N 语音与按键使用指南

更新日期：2026-11-16。已验证的 G9N9N 支持遥控器语音输入和 14 颗普通按键映射。

G9N9N 兼容款众多，不同硬件版本的功能支持可能不同，购买时请注意挑选硬件版本。购买与版本识别请查看[设备页面](https://remote.zfdang.com/device.html)；当前验证设备的公开身份为 Google Inc.、VID/PID `18D1:9450`、DIS 型号 `A0`、HID VersionNumber `0x0110`。型号名称或相同 VID/PID 不能单独代替实际按键测试。

本次测试设备由项目维护者实际购买并验证，[购买链接（拼多多，实购约 ¥15）](https://mobile.yangkeduo.com/goods.html?ps=wI005ehWCi)。

## 首次设置

1. 在 macOS 蓝牙设置中连接遥控器；配对时同时按住返回和主页约 3 秒。
2. 在向导选择 G9N9N，单按 OK 确认收到输入。
3. 依次单按三个不同的普通按键，完成按键检查，然后配置输入工具并测试语音。

## 按键映射

在“按键映射”选择 G9N9N，开启自定义按键。方向、OK、返回、主页、静音、音量加减、YouTube、Netflix、输入源和电源共 14 颗普通按键，可配置单击、双击和长按。语音键固定用于遥控器麦克风，不能作为普通键映射。

YouTube 默认上一首，Netflix 默认下一首，输入源默认播放／暂停；均支持自定义。单项“恢复默认”和整机重置使用同一套型号默认动作；单项恢复保留其他按键及触发方式的自定义。设备首次从未知型号识别为 G9N9N 时，会补齐缺失的型号默认动作；当前选中与后台设备行为一致，已有自定义（包括主动设为未设置）会保留。电量服务有读数时，设备卡片显示电量百分比。

## 语音操作

全程按住 Google Assistant 语音键说话，松开停止收音。音频由遥控器麦克风送入 Remote Buddy Mic，再交给所选输入工具识别。
