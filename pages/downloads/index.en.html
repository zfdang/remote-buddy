Remote Buddy for Windows

Built with native .NET 10 LTS (C# / WPF), self-contained with no runtime prerequisites.

Windows 64-bit Portable

Standalone Open Source

Connects remotes directly over native Windows BLE. Hold to talk to trigger input methods (WeChat Keyboard Ctrl+F5) or Windows Dictation (Win+H). Fully offline, zero telemetry.

Remote_Buddy_Windows_*_x64.zip x64 Portable Zip Archive (~67 MB) Windows 10 / 11 (64-bit)
Setup & Hardware Support Notes:
  • Virtual Audio Cable Required: Unlike the macOS app, the Windows edition does not bundle an in-box kernel driver. Please install the WHQL-certified VB-CABLE Driver ↗ before running.
  • Hardware Support: Verified with Google Chromecast Voice Remote (G9N9N) and Xiaomi Bluetooth Remote 2 / 2 Pro for voice streaming and full button customization (single click, long press, and double click mapped to shortcuts or media keys).
