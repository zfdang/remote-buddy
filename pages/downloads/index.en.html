Windows Quick-Start Notes:
  • Unzip & Run as Administrator: Extract to a permanent folder, then right-click RemoteBuddy.App.exe and choose Run as administrator to enable full kernel button capture, Doubao support, and shortcut injection into elevated apps.
  • Install VB-CABLE & Reboot: Use the in-app wizard's one-click installer (or run VBCABLE_Setup_x64.exe from the driver pack above), reboot Windows, and select CABLE Output (VB-Audio Virtual Cable) as your input tool's microphone.
