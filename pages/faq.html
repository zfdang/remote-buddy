常见问答 (FAQ)

汇总 Remote Buddy（遥控搭子）在硬件选购、语音触发、按键直通、常用语面板、应用集成、输入法生态、常见疑难排障以及 Windows 平台安装配置方面的完整解答。

硬件兼容

一、硬件支持与选购推荐

Remote Buddy 支持哪些遥控器？

Remote Buddy 并非所有蓝牙遥控器都能通用，而是针对各厂商专有的蓝牙语音传输协议与 HID 报告格式做了深度驱动适配。目前支持情况如下：

1. Google Chromecast Voice Remote（型号 G9N9N）：已全面支持 · 首选推荐
支持实时语音解码、专属自动保活（最长约 5 分钟连续录音）、14 颗物理按键全功能自定义与电池电量显示。特别提醒：市面上的 G9N9N 存在多种不同硬件或固件批次（目前我们已实测过 3 种已知批次），并非所有批次都支持全部 14 键独立映射（部分非标准批次仅能识别 2 键组合码甚至无法录音）。选购前请务必参阅 G9N9N 语音与按键兼容性指南 ↗，挑选已验证的推荐批次。

2. 小米蓝牙遥控器 2 / 2 Pro（型号 RC001 电池版 / RC003 充电版）：已支持
支持按住说话与 60 秒录音，支持全按键自定义。

3. T1 飞鼠键盘语音遥控器（T1-Remote）：已支持
须通过蓝牙直连 Mac（非 2.4G 接收器）。支持点按免提、正面 7 颗常用键自定义，背面自带约 45 键迷你全键盘与空中飞鼠。

4. 计划支持中：Google TV Streamer Voice Remote（型号 GY3LE）、Apple Siri Remote（如第 3 代 A2854）等已列入跟进规划，暂未开放生产使用。

重要提示：能在 Mac 系统蓝牙设置中成功配对，并不代表能录音或映射按键。普通遥控器若使用非标准私有语音协议，系统无法抓取音频流。详细参数与实拍请参阅 支持设备与购买指南 ↗。

推荐购买哪款遥控器？

根据日常使用偏好与预算，我们推荐以下选购策略：

1. 首选与性价比之王：Google G9N9N（约 ¥15）
在电商平台（如拼多多、淘宝等）价格仅需 15 元左右。语音键正好位于方向圆环正下方，单手大拇指盲操极其舒适自然；原生支持“智能切换”（可点按也可长按），且支持突破 60 秒上限的长录音。使用两节普通 AAA 7号电池，续航持久。注意：不同批次的 G9N9N 硬件表现有差异，购买前请参考 G9N9N 兼容批次指南 ↗ 选购。

2. 偏好金属质感与内置充电：小米蓝牙遥控器 2 Pro（日常约 ¥60~¥99）
铝合金拉丝机身，做工精致高档，底部带 Type-C 充电接口免换电池。缺点是语音键位于右上角，拇指需要向上伸够，且受限于硬件固件单次录音有 60 秒上限。

3. 大屏操作、移动光标或补敲文字：T1 飞鼠遥控器（约 ¥50）
正面具备遥控与语音功能，翻面即是全功能 QWERTY 键盘与 6 轴空鼠陀螺仪，特别适合躺椅或离开办公桌时远距离操作大屏。

Remote Buddy 有 Windows 版本吗？与 macOS 版有什么区别？

有。Remote Buddy 拥有独立的 Windows 开源版本，代码托管于独立的开源仓库：zfdang/remote-buddy-windows ↗。

两个版本的核心特性与区别如下：

  1. 技术栈与架构：macOS 版使用原生 Swift / AppKit 开发，针对 CoreAudio 与 IOHID 系统深度优化；Windows 版采用原生 C# / .NET 10 LTS (WPF) 构建，自包含单文件绿色免安装发布（无需预装 .NET 运行库）。
  2. 麦克风驱动：macOS 版内嵌了自主研发的 Remote Buddy Mic 虚拟麦克风驱动，随安装包一站式装好；Windows 版因内核驱动强制签名机制，需配合微软 WHQL 认证的第三方虚拟声卡 VB-CABLE Driver ↗（软件向导内置一键下载与安装入口，会优先从官网镜像下载并支持 VB-Audio 官网回退）。
  3. 按键与型号支持：两个版本均完整实现 ATVV 语音协议状态机与首尾音防护时序。已验证 Google Chromecast 遥控器（G9N9N）、小米蓝牙语音遥控器 2 / 2 Pro 与 T1 飞鼠遥控器，支持单击、长按、双击触发快捷键、媒体控制或常用文本。
  4. 输入法适配：支持微信输入法（默认 Ctrl + F5）、豆包输入法 / 客户端（支持通过签名 USB/IP 虚拟键盘驱动触发长按说话）、Windows 自带语音听写（Win + H）以及 Typeless（默认 Ctrl + Alt + V）等全局语音工具。

如果你使用的是 Windows 电脑，可直接前往 下载页 Windows 专区（或 Windows Releases 页面 ↗）获取压缩包，详细安装与配置步骤请参阅下方 六、Windows 平台安装与使用指南 ↓。

为什么有的遥控器不支持点按免提模式，而只能按住说话？

根本原因在于遥控器内部的硬件电路与蓝牙音频传输协议设计：

硬件电平与麦克风供电紧耦合（如小米遥控器）：专为电视盒子设计的遥控器，为了最大程度省电，将麦克风供电与语音按键的物理按下深度绑定——只有当你的手指按住物理键时，硬件电路才给麦克风通电并建立蓝牙推流；一旦手指松开，遥控器硬件芯片会立刻切断麦克风供电并终止音频发送。由于其固件不支持通过电脑下发指令来“远程开启并维持麦克风”，因此无论软件如何控制，松手后遥控器都无法再采集到任何声音。

为什么修改输入法设置也无效？不少用户尝试在微信输入法或豆包输入法中将设置改为“点按开始 / 点按结束”，发现依然无法点按免提。这是因为输入法的设置仅改变了电脑软件自身的等待状态，无法改变蓝牙遥控器芯片的物理断电行为。遥控器松手即停止推流，输入法自然也就收不到声音。

哪些遥控器能支持点按免提？
Google G9N9N：支持高级全双工双向控制指令。Remote Buddy 可以在你短按一下后，通过蓝牙指令让遥控器持续供电收音（底部白灯常亮），直到再次点按才发指令让其休眠。
T1 飞鼠遥控器：出厂固件原生设计即为“按一下开麦推流、再按一下关麦断流”的免提逻辑，无需手指持续按压。

为什么某些遥控器（如小米）具有 60 秒的物理上限？

底层原因分析：小米等电视盒子遥控器的硬件出厂固件原本是为家庭电视设计的。为了极致省电以及防止遥控器掉进沙发缝误压语音键导致电量耗尽，遥控器主控芯片内部硬编码了硬件看门狗定时器：一旦开启录音，单次音频传输达到约 60 秒时，硬件会自动强行切断蓝牙音频流。无论电脑端软件如何请求，硬件均不会再吐出音频数据，必须松开按键后重新按下才能开启下一段录音。

G9N9N 与 T1 为什么没有 60 秒断开限制？

G9N9N 与 T1 支持全双工蓝牙双向通信与状态协商。Remote Buddy 为其专门设计了链路保活包与自动分段续流（Keep-Alive）调度引擎，在录音进行中定期主动向遥控器发送保活信号，从而彻底绕过了电视固件的超时熔断，单次最长可稳定连续收音约 5 分钟，非常适合会议发言、长篇听写与深度写作。

操作逻辑

二、语音触发与按键模式

按键模式（点按免提）与长按模式（按住说话）的区别是什么？

Remote Buddy 提供了两种核心的语音触发范式，并在 G9N9N 上实现了两者的智能融合：

1. 长按模式（按住说话 / Hold to Talk）：
按住语音键时麦克风开始收音并触发输入工具；松开按键时立即停止录音并触发文本上屏。适合微信回复短消息、单句搜索、灵感备忘录等日常高频片段输入，操作最符合对讲机直觉。

2. 按键模式（点按免提 / Hands-Free Toggle）：
按一下语音键开启收音，此时双手可以完全脱离遥控器自由打字或查阅资料；整段讲话完毕后，再按一下语音键结束并上屏。非常适合持续几分钟的会议发言、长文听写口述等场景。

3. G9N9N 独有的“智能切换模式”（默认推荐）：
系统会自动根据你的按压时长做出精准裁决：如果按下时间小于 0.7 秒松手，自动判定为点按免提（持续收音，直至下次点按结束）；如果按下超过 0.7 秒，则自动转为按住说话（松手立即结束）。无需进设置切换，兼得两家之长。

为什么强烈建议避免使用 Fn 键作为语音热键？推荐使用什么热键？

核心原因：Fn / 地球键（🌐）是 macOS 系统与各类桌面应用中最容易发生冲突的单键。

  • 极易被第三方应用抢占：许多常用的桌面应用（最典型的如桌面端微信）会在后台静默注册全局 Fn 监听。一旦被占用，遥控器发出的 Fn 信号会被微信率先拦截，导致你选择的第三方语音输入工具根本收不到信号。
  • 容易触发 macOS 系统原生行为：在 macOS 默认设置中，按下 🌐 键通常用于“显示表情符号与符号”或“切换输入源”，经常导致屏幕弹出 Emoji 面板或打字法被切走。
  • 排查繁琐成本高：单键冲突非常隐蔽，一旦遇到语音失灵，用户往往需要在 macOS 系统设置、微信快捷键以及其他后台软件中逐个排查，排错体验很差。

官方推荐实践：

在 Remote Buddy 与你的输入工具中，强烈建议改用不易冲突的自定义多修饰组合键（例如 Ctrl (⌃) + Option (⌥) + V）作为语音热键：

多修饰组合键拥有极高的全局唯一性，几乎不会被系统功能或日常应用程序占用，无需任何繁琐的系统排查设置即可获得长期稳定、开箱即用的触发体验！

“按键映射”里每个按键都可以设置哪些动作？有什么常见的设置例子？

在「按键映射」页面开启自定义开关后，除语音键外，每颗实体按键的单击、双击、长按都可以分别设置不同动作，并且每台遥控器的配置互不干扰、独立保存。

目前可为每个键位设置的动作分为以下几类：

  • 基础按键：如回车、发送（⌘↩）、换行、复制/粘贴、撤销、上下左右光标与页面滚动等高频编辑操作。
  • 系统与媒体：切换应用（⌘Tab）、调度中心、聚焦搜索、播放/暂停、切歌、音量与亮度调节，以及关闭干扰按键等。
  • 打开具体 APP：不仅包含常用预设应用（如 Chrome、微信、Cursor、ChatGPT、Claude、终端等），还可以选「打开自定义 APP」添加 Mac 上的任意程序，并可选配置“打开后自动发送快捷键或定位焦点输入框”。
  • 常用语：将某个键设为唤起常用语浮动面板，快速插入邮箱、地址或长提示词。
  • 自定义动作：
    • 自定义快捷键：录制 Mac 上的任意单个按键或组合键（例如编辑器命令、录屏、全局触发键）。
    • 打开网址 / URL Scheme：填写网页链接（如 https://...）或应用协议（如苹果原生「快捷指令」的 shortcuts://run-shortcut?name=名称），一键打开页面或执行多步快捷指令组合动作。
  • 原样透传（方向键可选）：作为纯方向键直接按下/抬起，0 延迟响应，适合视频播放器长按倍速或光标持续移动。

常见设置示例：

  1. 单键秒开常用程序并直接开聊：把遥控器上的 YouTube 或 Netflix 键单击设为「打开具体 APP」（或「打开自定义 APP」选择 Cursor / 微信），点一下切过去就能直接按语音键说话。
  2. 单键打开网页或联动「快捷指令」做组合动作：把空闲键（例如 信源键 或 返回键 双击）设为「打开网址 / URL Scheme」——填入 https://chatgpt.com 即可一键打开网页版；或填入 shortcuts://run-shortcut?name=工作模式，按一下就能运行你编排好的多步「快捷指令」组合动作。
  3. 用“长按”扩展自定义快捷键：例如保留 确定键 单击为回车、长按为发送；再把 静音键 长按设为「自定义快捷键」（如 ⌘Space 或编辑器命令面板 ⇧⌘P），让一颗按键同时承担多种高频操作。
按键的“直通模式（Direct Passthrough）”是什么意思？用在什么场景下？

诞生背景：Remote Buddy 默认的普通按键支持“单击、双击、长按”三种手势。为了区分单击和双击，系统在用户按下按键后必须等待数十毫秒的手势判定窗口；且默认的长按手势是在持续按住 350ms 启动延迟后，以 100ms 为周期自动连发单击（软件连发）。

直通模式的工作机制：按键直通完全跳过手势判定与连击等待。当按下方向键时，遥控搭子以 0ms 延迟如实向系统底层发送按键按下（KeyDown）事件；当手指松开时，立即如实发送按键抬起（KeyUp）事件。其行为与键盘上的物理真实方向键 100% 保持一致。

典型应用场景：

  1. 主流视频播放器长按倍速播放：在 Bilibili、YouTube、各类本地播放器中，长按方向右键（→）会自动开启 2 倍速或 3 倍速播放，松手立刻恢复常速。在直通模式下，按住方向右键即可顺畅倍速，彻底解决原先按键连发导致跳跃快进的困扰！
  2. 文档光标平滑移动与游戏微调：上下左右精准微调光标、持续按住滚动页面、复古模拟器方向控制等。
  3. 安全防卡键看门狗：直通模式内置 60 秒安全看门狗定时器，即使遇到极端蓝牙丢包情况，也会在超时后自动补发 KeyUp 抬起事件，防止系统键盘按键被卡死。
“常用语（Common Phrases）”有什么用处？如何设置和唤出？

功能定位：用于高频固定文本的一键快速粘贴。例如你的个人邮箱、收件地址、常用客服话术、终端长命令、代码 Snippet 等，无需每次重复打字或语音念出。

设置与唤出方式：

  1. 打开 Remote Buddy「按键映射」界面，点击右下角的「调整常用语」按钮（或直接通过左侧导航进入「常用语」设置）。
  2. 在常用语管理面板中，可以编辑词条内容、设定简短标签，并将常用语直接分配绑定给遥控器上的实体按键（方向键、OK 键以及当前遥控器支持的功能键）。
  3. 在按键映射网格中，将任意按键的单击、双击或长按设置为「常用语」动作。

使用与独占保护机制：按下常用语唤出键后，屏幕中央会浮现常用语按键面板，展示各个按键绑定的词条。此时遥控器的按键会被常用语面板独占处理，按下对应按键即可将绑定的文本自动粘贴（通过虚拟按键模拟 Command+V）到当前输入框中。常用语面板关闭后，各按键立即恢复正常的映射或直通功能，互不影响。

高效协同

三、应用集成与核心作用

“应用集成”是干什么用的？它有什么作用？

核心作用：「应用集成」的作用是在支持的应用程序处于当前前台窗口时，按下语音键自动将光标定位到对话输入框中，避免因当前焦点不在输入框上而导致无法输入文字。

具体工作场景与原理：

  • 解决丢焦痛点，免除手动拿鼠标点击：在日常使用中，当你打开微信聊天窗口、ChatGPT、Antigravity、Claude、DeepSeek 或 WorkBuddy 时，经常会先用鼠标滚轮翻看历史消息或点击其他区域，此时光标焦点并不在输入框中。如果没有应用集成，直接按遥控器说话，识别出的文字会因为没有受焦的输入框而打在空气中。
  • 按下语音键自动智能对焦：开启对应应用集成后，按下遥控器语音键的瞬间，Remote Buddy 会通过 macOS Accessibility 辅助功能树，自动寻找并聚焦到该窗口的主消息输入框；如果你的光标本来就已经在某个输入框内，则会优先沿用当前选中的输入框。

输入工具

四、输入法生态与模式转换

目前为止支持哪些输入法和语音工具？

Remote Buddy 原生兼容所有支持通过全局快捷键唤醒语音且支持选择系统麦克风输入的 macOS 软件。内置官方适配的工具列表（按软件中的适配顺序排列）如下：

1. 微信输入法（WeType）：微信官方输入法，支持在输入法设置中配置语音快捷键，并可开启“快捷键全局生效”实现免切输入法极速唤起。

2. 豆包输入法（Doubao）：字节跳动推出的 AI 语音输入利器，识别准确度极高，具备大模型智能润色与“全局唤起语音”功能。

3. 腾讯 Chatterfly：通过全局语音快捷键，在腾讯 Chatterfly 中按住说话、松开结束。

4. Voice Buddy（语音搭子）：同系列自研离线推荐
基于 Apple Silicon 神经引擎实现 100% 本地离线 AI 语音输入与润色，声音与文字全程不上传云端，零隐私泄露风险，毫秒级响应，与 Remote Buddy 开箱即用完美协同。

5. 网易叭哥说（Bageshuo）：网易 AI 语音输入工具，主打端到端极速语音上屏与大模型内容润色修正。

6. Typeless：新一代极简现代跨平台智能语音输入工具，支持全局语音快捷键按住说话。

系统原生内置，无需安装第三方软件，在 Apple Silicon 设备上可离线运行。默认快捷键通常为连按两次 Fn（或系统自定义热键）。

输入工具设置中的“长按”与“点按”是什么意思？它和遥控器的长按、点按有什么区别？

很多用户容易将「遥控器的按键手势」与「输入工具的触发模式」混为一谈。实际上它们是完全独立的两个层级，彼此并没有直接绑定关系，Remote Buddy 在中间负责全自动转换与状态调度：

两者的本质区别：
1. 遥控器端的长按 / 点按：描述的是你的手指在遥控器实体硬件上的物理操作习惯（是喜欢按住说话、还是喜欢按一下松手免提说话）。
2. 输入工具端的长按 / 点按：描述的是你所使用的输入法软件（如系统听写、豆包、微信键盘等）自身接收快捷键的逻辑规则。

Remote Buddy 是如何实现两端双向转换的？（转换原理与举例）

  • 例子 1：遥控器是点按免提，而输入工具只支持长按模式
    转换方法：当你在遥控器上按一下语音键时，Remote Buddy 收到启动信号，立即在系统底层向输入工具发送快捷键的 KeyDown（持续按住不放），输入工具以为你一直按着键盘快捷键，开始持续收音；此时你双手脱离遥控器自由说话；说完后你再次按一下遥控器，Remote Buddy 收到结束信号，立即向系统底层发送快捷键的 KeyUp（松开按键），输入工具收到松开事件停止收音并上屏文字。
  • 例子 2：遥控器只支持长按（如小米），而输入工具只支持点按模式（如系统听写）
    转换方法：当你按住遥控器语音键时，Remote Buddy 会向系统模拟发送一次完整的快捷键敲击（KeyDown + KeyUp）唤醒输入工具开始收音；当你说话完毕松开遥控器按键时，Remote Buddy 捕捉到物理抬起信号，自动再向系统模拟发送一次完整的快捷键敲击（KeyDown + KeyUp），通知输入工具结束录音并转录。

官方推荐配置：输入工具一律推荐设为「长按模式」！

在支持自定义快捷键触发方式的输入工具（如豆包、微信键盘、Voice Buddy 等）中，我们强烈推荐将输入工具设置为「长按模式」（按住说话 / Hold to Talk）：

  1. 状态绝对确定，绝不串台翻转：点按模式是“开关翻转（Toggle）”，同一个快捷键按一下是开、再按一下是关。一旦输入工具偶发卡顿或丢焦，就可能出现“本该停止却重新开始”的状态颠倒；而长按模式是明确的“电平信号”——KeyDown 绝对代表正在录音，KeyUp 绝对代表结束上屏，逻辑最严密、容错率最高。
  2. 遥控器端自由随心：只要输入工具设为长按模式，你在遥控器端可以根据个人喜好随意选择按住说话或免提点按（在 G9N9N 上还可以使用智能切换混合双打），Remote Buddy 都会精准保持快捷键的按住与释放，体验最为稳定顺畅！

一句话配置技巧：在第三方输入工具软件里尽量设为「长按模式（按住说话）」，而在 Remote Buddy 中保持默认的「点按模式：已关闭」（即向导中不要开启“点按触发模式”开关）；而在物理遥控器上，你想按住说就按住说、想免提点按就免提点按，中间转换全由 Remote Buddy 自动搞定！

微信输入法和豆包输入法下的「已开启“快捷键全局生效”」选项是干什么用的？

背景与默认行为：微信输入法和豆包输入法在 macOS 上属于系统输入源（Input Source）。在默认情况下，如果你当前处于系统自带英文（ABC）或其它输入法，按下遥控器语音键时，Remote Buddy 会主动调用系统接口将输入法切换为微信输入法或豆包，以确保能够唤起语音输入。

为什么提供该选项？
在某些对焦点极其敏感的应用（例如 Antigravity、VS Code、终端（Terminal）或部分代码编辑器）中，系统层面的输入法切换（TIS 切换）可能导致正在编辑的输入框瞬间丢失光标焦点，或者引起轻微界面卡顿。
而微信输入法和豆包输入法客户端自身都支持后台全局监听唤起：

  • 微信输入法：在设置中支持「快捷键全局生效」（无需切换输入法，按下快捷键全局弹出语音浮窗）。
  • 豆包输入法：在设置中支持「全局唤起语音」。

选项的作用与效果：

  1. 跳过输入法切换，彻底杜绝丢焦：在 Remote Buddy 的「输入法集成」中开启该开关后，Remote Buddy 将完全不再主动切换 macOS 系统输入法，直接向系统派发语音快捷键。这彻底解决了 Antigravity、VS Code 等编辑器中的光标失焦问题。
  2. 零延迟极速唤起：由于省去了系统输入法上下文切换的等待时间，语音唤起更灵敏、零卡顿。

重要使用前提：
开启此选项前，务必确保已在对应输入法客户端内部开启了全局快捷键：
• 微信输入法：打开微信键盘设置 → 快捷键 → 勾选「快捷键全局生效」。
• 豆包输入法：打开豆包输入法设置 → 语音输入 → 开启「全局唤起语音」。
注意：若输入法本身未开启全局功能，而在 Remote Buddy 中开启了此选项，当系统处于英文 ABC 时按遥控器可能无法呼出语音。

下载 macOS 安装包（.pkg）后提示“无法打开……无法验证开发者”或“包含恶意软件”怎么办？

这是 macOS 对未经过 Apple 商业公证的开源安装包触发的正常 Gatekeeper 防护提示。Remote Buddy 为 GPL-3.0-only 开源免费软件，当前未购买收费的 Apple Developer ID 商业开发者证书及向苹果官方服务器提交公证（Notarization），因此通过浏览器下载的 .pkg（包含主安装包与通用卸载包）在直接双击时会被系统拦截。只要你确认包体来自官网镜像（remote.zfdang.com）或官方仓库 zfdang/remote-buddy Releases ↗，即可放心通过以下任一方式放行安装：

  1. 方法一：访达右键「打开」（推荐，适用于多数 macOS 版本）
    在「访达（Finder）」的「下载」目录中，按住 Control 键点击（或鼠标右键）.pkg 文件并选择「打开」，随后在弹出的确认框中点击「打开」即可进入安装向导。（注：macOS 15 Sequoia 及更新系统若右键仍不显示“打开”按钮，请改用下方方法二。）
  2. 方法二：在「系统设置」中放行（通用，支持 macOS 14 / 15 及以上）
    先关闭刚才的双击拦截弹窗，打开 Mac 的「系统设置」→「隐私与安全性」，向下滚动到「安全性」区域，找到“已阻止使用 Remote_Buddy_...pkg……”的提示并点击右侧「仍要打开」，输入开机密码或触控 ID 授权后即可继续安装。
  3. 方法三：终端命令移除隔离属性（命令行用户）
    在「终端」中运行以下命令清除下载文件的 Quarantine 隔离标记，之后即可直接双击 .pkg 安装（如安装卸载包或特定文件名，请替换为实际文件名）：
    xattr -d com.apple.quarantine ~/Downloads/Remote_Buddy_*.pkg

以上放行操作仅需在初次安装时执行一次，安装完成后日常使用和虚拟麦克风驱动运行不会再重复触发此提示。

为什么软件需要“辅助功能”、“输入监控”和“麦克风驱动”权限？会泄露隐私吗？

我们承诺：Remote Buddy 100% 纯本地运行、零遥测、不保存任何音频或文字，代码完全以 GPL-3.0-only 开源在 GitHub，绝不泄露隐私。

各项权限的具体作用：

  • 麦克风音频驱动（Remote Buddy Mic）：这是系统级的 CoreAudio HAL 虚拟驱动。遥控器传来的蓝牙原始压缩音频经本地解码后，送入该虚拟驱动，让 macOS 认为连接了一只真实的专业物理麦克风。驱动源码随主程序完全开源。
  • 辅助功能权限（Accessibility）：用于模拟键盘修饰键与快捷键、调度常用语面板以及智能探测聚焦目标窗口的输入框。
  • 输入监控权限（Input Monitoring）：用于直接捕获特定遥控器发出的 HID 物理按键事件，确保在后台时依然能稳定响应遥控器操作。
语音正常，按键却没反应？先检查 Karabiner-Elements 等按键工具的设备占用。

这类工具可能独占遥控器，导致遥控搭子收不到按键。典型表现是普通按键无法执行已配置的动作，而蓝牙连接或语音仍然正常。小米遥控器的默认映射中，主页键切换应用、TV 键播放/暂停、电源键退格、返回键发送 Escape。

  1. 在 Karabiner-Elements 中打开 Devices（设备），找到你的遥控器，例如“小米蓝牙语音遥控器”。
  2. 关闭这只遥控器的 Modify events，把它交给遥控搭子处理。其他键盘的设置可以保留。
  3. 重新连接遥控器，或重启遥控搭子，再到“按键映射”检查连接状态，测试主页键、TV 键、电源键与返回键。

若仍提示“设备被其他输入工具占用”，可重启 Karabiner-Elements 后再试；同时检查遥控搭子的输入监控与辅助功能权限。

选择 Fn 键触发语音，却没反应或被微信截获？检查微信全局快捷键占用。

macOS 版微信（WeChat App）可能在后台注册了全局 Fn 快捷键（例如全局语音输入或其他功能热键）。一旦被微信占用，按下遥控器发送的 Fn 会先被微信拦截，导致你选择的第三方语音输入工具（如豆包、微信输入法、腾讯Chatterfly、Typeless 等）无法收到触发信号。

  1. 打开桌面端微信 → 设置 → 快捷键（部分版本在聊天/通用设置内）。
  2. 检查是否存在占用 Fn（或 🌐 地球键）的全局快捷键，尤其是语音输入相关热键。
  3. 如有冲突，请更换或仅清除冲突的 Fn 快捷键（无需修改微信其他快捷键）。

  1. 打开 macOS 系统设置（System Settings）→ 键盘（Keyboard）。
  2. 找到 按下 🌐 键时（Press 🌐 key to） 下拉菜单，将其设为 不执行任何操作（Do Nothing）。
  3. 如在其它软件中不希望按 Fn 弹出表情或切换输入法，改完后系统即会直接放行 Fn 给语音输入工具使用。

为什么设置“调度中心”、“通知中心”、“显示桌面”或“聚焦搜索”等系统动作后不生效？

核心原理：Remote Buddy 内置的「调度中心 (⌃↑)」「通知中心 (fn N)」「显示桌面 (fn F11)」「上一/下一桌面 (⌃← / ⌃→)」「聚焦搜索 (⌘Space)」「截屏 (⇧⌘5)」等系统与媒体动作，以及通过「自定义快捷键」配置的组合键，本质上只是向 macOS 发送对应的系统默认快捷键，并不直接绕过系统设置去调用私有内部接口。

因此，这些映射能否触发，完全取决于你的 Mac 是否已开启并保留了对应的系统快捷键：

  1. 前往正确的系统快捷键设置位置核对：
    打开 系统设置（System Settings）→ 键盘（Keyboard）→ 键盘快捷键…（Keyboard Shortcuts…）→ 调度中心（Mission Control）（或其他对应分类），确认相关快捷键处于勾选启用状态，且与发送的按键一致（例如：调度中心 → ⌃↑、应用程序窗口 → ⌃↓、显示桌面 → F11 等）。
  2. 注意区分容易混淆的设置路径：
    在较新的 macOS 中，系统设置 → 桌面与程序坞 → 调度中心 仅控制窗口分组、显示器独立空间等行为偏好，并不包含快捷键开关或键位设置；修改快捷键必须进入上一条的「键盘 → 键盘快捷键」。
  3. 关于“聚焦搜索 (⌘Space)”与输入法冲突：
    部分多输入法用户可能会把 ⌘Space 分配给「选择上一个输入源」而非「显示“聚焦”搜索」。如需使用聚焦搜索，请同步在「键盘快捷键 → 聚焦 / 输入法」中确认键位。
  4. 不想改回系统默认键位？
    如果在 macOS 中习惯使用其他自定义热键触发这些功能，只需在 Remote Buddy 按键映射中改选「自定义快捷键」，并通过内置虚拟键盘录入你自己在系统设置里绑定的按键组合即可。

为什么在密码框或安全终端（如 iTerm2、1Password）中按键或常用语无法粘贴？

这是完全正常的操作系统安全行为，而非软件故障。

macOS 拥有一套内核级安全保护机制——安全输入模式（Secure Input Mode）。当光标停留在任何密码输入框、钥匙串授权窗口、锁定凭据管理器（如 1Password / Bitwarden）或开启了安全输入的终端窗口时，macOS 内核会强行阻断所有第三方软件的模拟按键、剪贴板自动化注入与键盘监听，防止恶意间谍软件窃取明文密码。

此时 Remote Buddy 的模拟按键与常用语粘贴会被系统静默保护拦截。只需将光标移出密码框或切回普通文本窗口，所有功能便会自动恢复正常。

遥控器如何重新配对或清除绑定？

当需要更换电脑或遇到蓝牙连接状态异常时，可按各机型方法重置与配对：

  1. Google G9N9N：
    • 重新配对广播：同时长按正面的「返回（Back）」与「主页（Home）」键约 3 秒，直到机身底部的白色指示灯开始慢闪呼吸，进入蓝牙广播配对状态；在 Mac「系统设置 → 蓝牙」中忽略旧记录并重新配对。
    • 出厂重置（Hard Reset）：若蓝牙死锁，取出两节 AAA 电池，按住正面的「主页键」不松手同时装回电池，继续保持按住直到指示灯由常亮变为脉冲闪烁后再松开，遥控器即可完全重置并自动进入待配对状态。（注：遥控器本体上没有圆形物理按键，请勿与 Chromecast 电视棒机身上的按钮混淆）。
  2. 小米蓝牙遥控器 2 / 2 Pro（RC001 / RC003）：
    • 重新配对广播：靠近设备（建议 10~20 厘米），同时长按「主页键」与「菜单键」约 3~5 秒，听到滴声或指示灯快闪即进入配对状态；在 Mac 蓝牙中搜索并连接。
    • 清除旧绑定 / 复位：在原设备的蓝牙列表中点击“忽略/删除此设备”；RC001 电池版可取下电池断电复位，RC003 2 Pro 充电版若无响应可插入底部 Type-C 充电线唤醒并重新长按配对。
  3. T1 飞鼠键盘语音遥控器（T1-Remote）：
    • 蓝牙直连配对：同时长按「主页键（Home）」与「返回键（Back）」，直到指示灯由快闪转为慢闪，进入蓝牙广播配对状态（配对 Mac 必须使用蓝牙直连 T1-Remote，勿插 2.4G 接收器）。
    • 异常复位：取下电池断电数秒后再装入（内置锂电款插侧面 Type-C 充电复位），重新执行 Home + Back 配对。

六、Windows 平台安装与使用指南

Windows 版下载完成后如何安装与开始使用？

Windows 版采用自包含（Self-Contained）.NET 10 LTS 绿色包发布，无需单独安装 .NET 运行库。按以下步骤即可快速完成初次配置：

  1. 下载并完整解压：在 下载页 Windows 专区 下载 Remote_Buddy_Windows_*_x64.zip，将其完整解压到一个固定文件夹（例如 D:\Tools\RemoteBuddy）；请勿直接在压缩包预览窗口中双击运行。
  2. 以管理员身份运行主程序：进入解压目录，右键点击 RemoteBuddy.App.exe，选择「以管理员身份运行」并在 UAC 弹窗中确认。首次运行如遇到 Windows SmartScreen 提示，可点击「更多信息 → 仍要运行」。
  3. 安装 VB-CABLE 虚拟麦克风并重启电脑：首次打开会进入配置向导。第 2 步「检查虚拟麦克风驱动」如果检测到未安装，直接点击「安装 VB-CABLE」，程序会从官网镜像下载 VBCABLE_Driver_Pack46.zip（失败时自动回退 VB-Audio 官网）并校验 SHA-256，随后弹出官方安装器；在安装器中点击 Install Driver，完成后重启 Windows 让系统音频服务注册虚拟端点。
  4. 蓝牙配对并在应用内点击“连接”：先在 Windows 系统蓝牙设置中配对遥控器（或进入向导「连接遥控器」步骤扫描）。重要：即使 Windows 蓝牙已显示“已配对/已连接”，仍需在向导或「设备」页面点击该遥控器右侧的「连接」按钮，才能建立 ATVV 语音通道并开始按键检测。
  5. 配置输入法麦克风与语音热键并验收：在输入法或语音工具设置中将录音麦克风选为 CABLE Output (VB-Audio Virtual Cable)，使语音热键与 Remote Buddy 向导一致，最后在向导中完成一次「语音转写验收」即可日常使用。
为什么 Windows 版必须安装 VB-CABLE 虚拟麦克风？安装后电脑没声音怎么办？

为什么需要单独安装 VB-CABLE？
在 64 位 Windows 10/11 上，内核强制驱动签名机制（DSE）要求虚拟声卡驱动必须具有微软官方 WHQL 认证签名，自签名驱动无法加载。因此 Windows 版不像 macOS 版那样内嵌自研驱动，而是采用由 VB-Audio Software 提供的微软 WHQL 认证虚拟声卡 VB-CABLE（Donationware 免费可用）：Remote Buddy 将解码后的 16kHz 音频写入 CABLE Input，输入法则从配对的虚拟麦克风 CABLE Output 读取语音。

两种安装途径：

  • 软件内一键安装（推荐）：在设置向导第 2 步或主界面「权限与驱动」页面点击「安装 VB-CABLE」，按提示同意 UAC 提权后在弹出窗口点击 Install Driver，安装结束后重启电脑。
  • 手动提前安装：也可在 下载页 或 VB-Audio 官网 ↗ 下载 VBCABLE_Driver_Pack46.zip，解压后右键以管理员身份运行 VBCABLE_Setup_x64.exe，点击 Install Driver 并重启电脑。

常见安装后排障：

  • 装完 VB-CABLE 后电脑扬声器/耳机突然没声音：这是最常见现象——Windows 安装新声卡后有时会自动把系统默认播放输出设备切换为 CABLE Input (VB-Audio Virtual Cable)。只需点击任务栏右下角音量图标（或打开「系统 → 声音」），把默认输出设备改回你的物理扬声器或耳机即可恢复外放；同时不要更改输入法里选中的 CABLE Output 麦克风。
  • 提示需要重启或设备未就绪：VB-CABLE 官方明确要求安装或更新后重启 Windows 以完成音频端点注册，请保存工作后重启电脑再检测。
  • 检测到设备被禁用：在 Windows「声音设置 → 更多声音设置」中确认 CABLE Input（播放）和 CABLE Output（录制）均处于启用状态。
为什么强烈建议在 Windows 上“以管理员身份运行” Remote Buddy？

虽然不提权也能启动应用主界面，但在 Windows 下强烈建议始终以管理员身份（Administrator）运行 Remote Buddy，核心原因有四点：

  1. 完整捕获遥控器普通按键（BthPort ETW 内核跟踪）：在 Windows 上，Google Chromecast (G9N9N) 的多数普通按键以及 小米遥控器 2 Pro (RC003) 的返回、音量加、音量减键，系统不会完整交付给普通权限的 Raw Input 监听，需要依赖 Windows 内核蓝牙事件跟踪（BthPort ETW）补取。以管理员身份运行时，ETW 服务可在进程内原生直接运行，无需反复弹出 UAC 提权工作进程确认。
  2. 支持豆包输入法的 USB/IP 虚拟键盘驱动：豆包输入法的「长按模式」会忽略带有 LLKHF_INJECTED 标志的软件模拟按键（普通 SendInput 无法唤起）。当你在向导中选择豆包时，Remote Buddy 会通过微软签名的 usbip-win2 与 HIDMaestro 创建硬件级 USB/IP 虚拟键盘来发送语音快捷键，该虚拟键盘通道需要管理员权限。
  3. 避免 Windows UIPI 权限隔离导致热键失效：根据 Windows 安全架构，普通权限进程无法向“以管理员身份运行”的前台窗口（例如管理员终端/PowerShell、任务管理器或部分提权软件）发送模拟快捷键或粘贴常用语；以管理员身份运行 Remote Buddy 后即可在这些高权限窗口正常语音输入。
  4. 驱动安装与蓝牙适配器一键恢复：在软件内安装 VB-CABLE 驱动，或当遥控器连接异常时使用向导中的「重启蓝牙适配器」恢复功能，均需管理员权限。

如何一劳永逸地默认以管理员身份启动？
右键点击 RemoteBuddy.App.exe → 属性 → 兼容性 → 勾选「以管理员身份运行此程序」并确定；如果已经以普通权限打开，也可在软件左侧「权限与驱动」页面点击「以管理员身份重启本程序」。

Windows 上如何配置微信输入法、豆包输入法、Windows 语音听写和 Typeless？

通用前置条件：确保已在目标输入法或 Windows 系统录音设置中选择 CABLE Output (VB-Audio Virtual Cable) 作为麦克风输入设备，且配置的语音快捷键与 Remote Buddy 向导一致。

  • 微信输入法（WeType）：打开微信输入法设置 →「语音输入」页，勾选「快捷键全局生效」并选择「按住说话」（默认快捷键推荐 Ctrl + F5），将麦克风设为 CABLE Output (VB-Audio Virtual Cable)；在 Remote Buddy 中同样保持「按住说话」。
  • 豆包输入法 / 客户端：打开豆包设置 →「语音输入」页，将「全局唤起语音」设为「持续模式」，麦克风设为 CABLE Output (VB-Audio Virtual Cable)，确保豆包「长按模式」快捷键与 Remote Buddy 完全一致（区分左右修饰键）（例如默认的右 Alt RAlt，或左 Ctrl + Shift + D）。请以管理员身份运行 Remote Buddy 并选择「按住说话」，首次使用会自动准备已签名的 USB/IP 虚拟键盘驱动。
  • Windows 语音听写（Win + H）：Windows 10/11 原生内置，无需安装第三方软件。将 Windows 系统默认输入麦克风设为 CABLE Output (VB-Audio Virtual Cable)，向导中选择「Windows 语音听写」（快捷键 Win + H，单击切换开始与停止）。
  • Typeless 及其他全球热键语音工具：Typeless 默认语音快捷键为 Ctrl + Alt + V（按住说话）；其他支持全局热键的工具只需在工具中选定 CABLE Output 麦克风并在 Remote Buddy 向导录入对应快捷键即可。
Windows 版常见注意事项与排障（按键附加映射、已配对却无反应、SmartScreen 提示）
  • 为什么修改普通键映射后，系统原本的动作（如调音量、主页键）有时仍会同时触发？
    这是 Windows Raw Input 与低级钩子的系统机制限制：Raw Input 是被动监听接口，无法单独“吞掉”遥控器原始按键而不误伤物理键盘。因此 Windows 版普通键默认采用附加映射（Additive Mapping）——触发你设置的快捷键或常用语的同时，部分系统原生动作（例如音量调节）仍可能发生。
  • Windows 蓝牙已经显示“已配对/已连接”，但软件里没声音或普通键不响应怎么办？
    1) 请先确认已在 Remote Buddy 向导或「设备」页面手动点击该遥控器的「连接」按钮建立 ATVV 音频会话；
    2) 若语音正常但 G9N9N 普通键或小米 RC003 返回/音量键无反应，打开主界面「权限与驱动」，确认已处于管理员权限且「ETW 底层按键捕获服务」正在运行；若异常可点击「重试启动捕获」或以管理员重启程序；
    3) 若蓝牙连接卡死或出现报文截断警告，可直接使用向导中的「重启蓝牙适配器」按钮（或在设备管理器中禁用再启用蓝牙适配器）后重新连接。
  • 首次运行提示“Windows 已保护你的电脑”（SmartScreen 警告）安全吗？
    本项目为 GPL-3.0-only 开源免费软件，发布包暂未购买商业代码签名证书，因此初次下载解压运行可能触发 Windows Defender SmartScreen 提示。只要你确认包体来自官网镜像（remote.zfdang.com）或官方仓库 zfdang/remote-buddy-windows ↗，即可放心点击「更多信息 → 仍要运行」。
