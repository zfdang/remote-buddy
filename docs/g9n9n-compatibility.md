# G9N9N 语音与按键使用指南

更新日期：2026-11-16。市面上的 G9N9N 遥控器在 macOS 上存在**两种截然不同的硬件/固件表现**，因此 Remote Buddy 对应提供 **Fully Supported（完全支持模式）** 与 **Partially Supported（部分支持模式）** 两种运行模式：

| 硬件/固件类型 | macOS 识别表现 | 进入的模式 | 可用功能边界 |
| --- | --- | --- | --- |
| **信号正常被 macOS 识别的批次**（如已验证的 `HID VersionNumber 0x0110`） | 单键与松开均发送完整 3 字节报告，macOS 正常接收并上送 `IOHID` | **Fully Supported（完全支持模式）** | 语音键 + 全部 14 颗普通按键的单击、双击、长按与单键常用语 |
| **单键信号不被 macOS 识别的批次**（如历史实测的 `DIS A0 / 固件 26.7`） | 描述符声明 2 个槽位，但单键与松开仅发送 1 字节短报告，macOS 不认识并直接丢弃（仅双键同时按下能填满 2 字节进入 `IOHID`） | **Partially Supported（部分支持模式）** | **1. 语音键可正常按住使用；<br>2. 仅「方向键 + OK」（如「上 + OK」）可发送 Enter 键**；其余 14 颗普通单键、双击/长按及单键常用语不可用 |

> **关键说明与更换建议**：如果您的 G9N9N 属于第二类（单按不被 macOS 识别，只能靠双键组合触发），**必须由用户在向导中主动勾选确认进入 Partially Supported（部分支持）模式**；程序不会绕过您的确认自动切入有限支持模式。由于该模式下 14 颗普通按键、双击/长按及单键常用语均无法使用，**功能缺失较多，建议更换为完全兼容 macOS 的 G9N9N 硬件版本或其他已验证完全支持的遥控器**。

G9N9N 兼容款众多，同为 VID/PID `18D1:9450` 甚至同报 DIS 型号 `A0` 的设备，仍可能处于上述两种情况之一。购买与版本识别请查看[设备页面](https://remote.zfdang.com/device.html)；型号名称或相同 VID/PID 不能单独代替实际按键测试。

## 首次设置与模式识别

1. 在 macOS 蓝牙设置中连接遥控器；配对时同时按住返回和主页约 3 秒。
2. 在向导选择 G9N9N，先**单按 OK 键**测试：
   - **若收到单键输入**：自动判定为**完全支持模式**，随后依次单按三个不同的普通按键即可进入语音配置。
   - **若单按无反应**：向导提示尝试同时按住 **「上 + OK」**（任意方向键 + OK）。若只有双键组合才触发识别，需由用户**主动勾选启用「部分支持（双键兼容）模式」**，随后确认一次「方向键 + OK」可用即可继续语音配置，完成页会明确提示当前仅支持语音键和「方向键 + OK」发 Enter。

## 按键映射与兼容模式

在“按键映射”选择 G9N9N 并开启开关：

- **完全支持模式**：方向、OK、返回、主页、静音、音量加减、YouTube、Netflix、输入源和电源共 14 颗普通按键，可配置单击、双击和长按。YouTube 默认上一首，Netflix 默认下一首，输入源默认播放／暂停；均支持自定义。单项“恢复默认”和整机重置使用同一套型号默认动作；设备首次从未知型号识别为 G9N9N 时，会补齐缺失的型号默认动作（已有自定义包括主动设为未设置会保留）。
- **部分支持模式（双键兼容）**：页面可随时与“完全支持”互切；处于部分支持模式时，仅响应 **「方向键 + OK」→ 发送一次 Enter（回车）**，并隐藏不适用的 14 颗单键及单键常用语编辑项。

语音键始终固定用于遥控器麦克风，电量服务有读数时设备卡片显示电量百分比。

## 语音操作

全程按住 Google Assistant 语音键说话，松开停止收音。音频由遥控器麦克风送入 Remote Buddy Mic，再交给所选输入工具识别。两种模式下的语音操作完全一致。

[完整支持与部分支持（A0 / 26.7）两类真机测试记录](g9n9n-hardware-debugging.md)。

## 硬件与报告边界

部分支持模式下不通过双键组合推断全部 14 颗单键，也不开放缺乏松开报告的按键连发或长按逻辑，仅稳定提供「方向键 + OK」模拟 Enter 键。已识别的短零值松开报告会清除按键状态，不会作为新的电源键输入。
