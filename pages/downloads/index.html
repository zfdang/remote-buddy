Windows 快速上手提示：
  • 解压后以管理员身份运行：请完整解压到固定文件夹，右键 RemoteBuddy.App.exe 选择「以管理员身份运行」，即可开启完整底层按键捕获、支持豆包输入法及向管理员窗口注入快捷键。
  • 先装 VB-CABLE 驱动并重启：可在软件内向导一键安装（或使用上方驱动包以管理员运行 VBCABLE_Setup_x64.exe），安装完成后建议重启 Windows，并在输入法中将麦克风设为 CABLE Output (VB-Audio Virtual Cable)。
  • 详细教程与源码：完整配置与排障请参阅 Windows 平台安装与使用指南 (FAQ) → · Windows 开源仓库 ↗。
